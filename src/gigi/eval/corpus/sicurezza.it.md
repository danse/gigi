# Sicurezza degli account

## Accesso

Tutti gli accessi passano dal single sign-on. Le applicazioni interne
richiedono MFA: la password da sola non basta, serve il codice dell'app di
autenticazione o la chiave fisica.

## Password

Le password devono avere almeno 12 caratteri. Al primo accesso il portale
chiede di cambiare quella provvisoria. Il gestore password condiviso conserva
le credenziali di servizio; le credenziali personali non vanno mai salvate nei
repo.

## Incidenti

Se sospetti un uso non autorizzato, ruota subito le credenziali e apri un
ticket di sicurezza. Il team di sicurezza risponde entro un'ora negli orari di
ufficio.
