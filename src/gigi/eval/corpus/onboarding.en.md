# Onboarding a new teammate

When someone joins the team, run `make setup` in a fresh clone of the repo.
This creates the Python virtual environment, installs the toolchain, and writes
a local `.env` file with the development defaults.

Next, add the person to the GitHub organization and to the `#team` Slack
channel. Grant read access to the wiki and write access to the docs repo. The
manager schedules a 1:1 for the first week and defines the probation goals
together with the assigned buddy.

Finally, forward the new teammate the security briefing (passwords, MFA) and
the expense policy link found in the handbook.
