# Accessibilitat web

Els continguts públics han de complir les pautes WCAG 2.1 nivell AA. Totes les
imatges amb contingut porten text alternatiu, els formularis tenen etiquetes
associades i el contrast de text és almenys 4.5:1.

Les interaccions clau s'han de poder fer amb teclat i navegar amb lector de
pantalla. Cada nova pantalla passa una revisió d'accessibilitat abans de
publicar-se; les regressions d'accessibilitat són prou greus per bloquejar el
desplegament.

La plantilla de disseny inclou caps de focus visibles i zones de toc de 44
píxels com a mínim.
