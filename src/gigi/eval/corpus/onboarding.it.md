# Accoglienza di un nuovo membro

Quando qualcuno entra nel team, esegui `make setup` in un clone nuovo del repo.
Lo script crea l'ambiente virtuale Python, installa il toolchain e scrive un
file `.env` locale con le impostazioni di sviluppo di default.

Poi aggiungi la persona all'organizzazione GitHub e al canale Slack `#team`.
Concedi accesso in lettura alla wiki e scrittura al repo della documentazione.
Il manager fissa un colloquio 1:1 per la prima settimana e definisce gli
obiettivi del periodo di prova insieme al buddy assegnato.

Infine, invia al nuovo membro il briefing di sicurezza (password, MFA) e il
link alla policy di rimborsi riportata nel manuale.
